# Online Courses Analysis Dashboard

## Project Overview
This project presents an interactive dashboard built using Power BI to analyze online course data across different categories, languages, skills, ratings, and course durations. The dashboard helps identify trending learning areas, popular course categories, and user engagement patterns.

## Problem Statement
With thousands of online courses available across multiple platforms, it becomes difficult to identify:
- Which course categories are most popular
- Which skills are currently in demand
- Which languages attract the highest audience
- How course duration impacts viewership and ratings

This dashboard provides data-driven insights to answer these questions.

## Dataset Features
The dataset includes:
- Course Title
- Category
- Sub-category
- Language
- Duration
- Rating
- Skills
- Number of Views
- Instructor Information

## Dashboard Features
### Interactive Filters
- Category-wise filtering
- Course type filtering

### Visualizations Used
- Bar Charts
- Pie Charts
- Tables
- Word Cloud
- Trend Analysis Charts
- Category Comparison Charts

## Key Business Insights
- Identified the most popular course categories based on views.
- Analyzed the most demanded technical and professional skills.
- Compared language-wise course popularity.
- Evaluated viewer engagement based on course duration.
- Highlighted top-performing course segments.
